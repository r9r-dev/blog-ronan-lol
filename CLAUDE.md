## Project overview

Personal blog at **ronan.lol**. Static site, generated by **Astro 6** from markdown in `posts/`, served as plain HTML in production. Three-column reading layout (TOC rail, article body, meta rail) inspired by maggieappleton.com.

## Stack

- **Astro 6** with content collections (Zod-validated frontmatter), view transitions
- **Bun 1.3** runtime + package manager
- **Shiki** (`rose-pine-moon` theme) for syntax highlighting at build time
- **Pagefind** for full-text search, indexed at build
- **Source Serif 4** body + **Fraunces** display + **JetBrains Mono** code, via Google Fonts
- **nginx:alpine** for production serving (multistage Dockerfile)

## Commands

```sh
bun install            # install deps
bun run dev            # dev server on :4321 (HMR)
bun run build          # static dist/ + Pagefind index
bun run preview        # preview built dist
bun astro check        # type-check (requires @astrojs/check)
```

## Important patterns

### Content loader

`src/content.config.ts` uses `glob({ pattern: '**/*.md', base: './posts' })`. Project root is the repo root. Posts at `posts/<slug>/<file>.md` or `posts/<slug>.md`. The slug derives from the file's id, with `/index` suffix stripped.

### Frontmatter schema

Tags accept both array and comma-string formats (legacy data). Date is coerced. `type` defaults to `Note`. `draft: true` excludes the post from the index, RSS, sitemap, and routing.

### Three-column post layout

`PostLayout.astro` uses CSS grid at `min-width: 1024px`: TOC left rail, body center (62ch measure), meta rail right. Children placed by class. Below 1024px it collapses to a single column.

### View transitions + client scripts

`<ClientRouter />` is mounted in `BaseLayout`. Scripts in `src/scripts/` re-attach handlers on the `astro:page-load` event so they survive soft navigations.

### Visual system

OKLCH where authored, hex where borrowed from Maggie's actual tokens. Five-color palette (crimson, salmon, sea-blue, gold, purple) used for tags + cover panels. Layered warm-tinted shadows. Rounded corners (`.4rem`-ish). No `#000` / `#fff`.

## Deployment

```sh
docker build -t ronan-lol .
docker run --rm -p 8080:80 ronan-lol
```

Build context = repo root. Dockerfile installs deps, copies source + posts, runs `bun run build` (Astro + Pagefind), then nginx serves `dist/`.

## Notes

- All commands run from repo root (no longer `src/`).
- No backend, no API, no runtime cache — everything is static.
- New posts require a rebuild. Dev server hot-reloads on file change.
