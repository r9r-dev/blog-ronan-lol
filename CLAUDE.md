# CLAUDE.md

Guidance for Claude Code working in this repository.

## Project overview

Personal blog at **ronan.lol**. Static site generated by **Astro 6** from markdown. Two content sections: `garden/` (digital garden, evolving notes with growth stages) and `articles/` (finished long-form pieces). Maggie Appleton-faithful dark visual system.

## Stack

- **Astro 6** with two content collections (`garden`, `articles`), MDX support, view transitions
- **Bun 1.3** runtime + package manager
- **Vitest** for utility tests
- **Shiki** (`rose-pine-moon` theme) for syntax highlighting at build time
- **Pagefind** for full-text search, indexed at build
- **Canela Deck** display + **Canela Text** body (self-hosted from `public/fonts/`, extracted from macOS catalog) + **Lato** sans for nav/eyebrows + **JetBrains Mono** code (via Google Fonts)
- **nginx:alpine** for production serving (multistage Dockerfile)

## Commands

```sh
bun install            # install deps
bun run dev            # dev server on :4321 (HMR)
bun run build          # static dist/ + Pagefind index
bun run preview        # preview built dist
bun run test           # vitest run
bun run test:watch     # vitest watch
```

## Important patterns

### Content collections

Two collections in `src/content.config.ts`:

- **garden** — `posts/garden/`. Schema adds `growthStage` (`seedling | budding | evergreen`, default `seedling`) and optional `lastTended` date. Sort order: `lastTended ?? date` desc.
- **articles** — `posts/articles/`. Schema adds optional `type` (default `Article`) and optional `readTime`. Sort order: `date` desc.

Slugs derive from file id with `/index` stripped (e.g. `posts/garden/2024-01-15-typescript/index.md` → `2024-01-15-typescript`).

`draft: true` in any post excludes it from listings, RSS, sitemap, and `getStaticPaths`.

### Article responsive grid

`PostLayout.astro` uses a single CSS grid (`.article-grid`) with three breakpoints:

- **≥ 1340px** — three columns: `[TOC] [BODY (38rem)] [NOTES]`. Both rails sticky.
- **1024-1339px** — two columns `[TOC] [BODY]`. Notes drop to row 3 below body.
- **< 1024px** — single column. TOC becomes a collapsible card on top.

Body width stays fixed at `--measure: 38rem` until the 1024 breakpoint forces single-column. Header is placed inside the body column so it aligns with the body, not the rails.

### Fonts (Canela)

Canela Deck/Text are self-hosted at `public/fonts/*.woff2`, extracted from the macOS system catalog by `scripts/extract-fonts.py`. Apple's catalog ships **Regular (400), Medium (500), Bold (700)** + italics — no Light or SemiBold. CSS uses these weights only. Fallback chain in `--font-display` (`Fraunces`) and `--font-body` (`Source Serif 4`) lets the site degrade gracefully if Canela is removed.

Re-extract fonts: `python3 -m venv /tmp/font-extract-venv && source /tmp/font-extract-venv/bin/activate && pip install fonttools brotli && python3 scripts/extract-fonts.py && deactivate`.

### View transitions + client scripts

`<ClientRouter />` is mounted in `BaseLayout`. Scripts in `src/scripts/` re-attach handlers on the `astro:page-load` event so they survive soft navigations. `TocRail.astro` re-binds its scroll-spy and toggle on each navigation the same way.

### Visual system

Dark warm palette. Five-color accent set (crimson, salmon, sea-blue, gold, purple) plus orange. Brand crimson; sea-blue accent micro-marks; gold for garden eyebrow; crimson for articles eyebrow. Layered shadows. Soft borders. No `#000` / `#fff`.

Quote markdown (`> ...`) renders as a head-less quote-card. Rich quotes use the `<QuoteCard>` MDX component (avatar + author + date). Sidenotes use frontmatter `notes: { 1: "..." }` map and `<Sidenote num={1} />` (or manual `<sup class="sidenote-ref">`) inline refs — `NotesRail` reads from `notes` prop on PostLayout.

## Deployment

```sh
docker build -t ronan-lol .
docker run --rm -p 8080:80 ronan-lol
```

Build context = repo root. Dockerfile installs deps, copies source + posts, runs `bun run build` (Astro + Pagefind), then nginx serves `dist/`.

CI: pushing to `main` builds `:latest` on ghcr.io. Tagging `v*` builds the versioned image. Production runs `docker compose pull && docker compose up -d` from `/home/share/stacks/blog` on cadence.

## Notes

- All commands run from repo root.
- No backend, no API, no runtime cache — everything is static.
- New posts require a rebuild. Dev server hot-reloads on file change.
- Canela served under personal-use risk (Apple bundle ≠ web license). Fallback to Fraunces / Source Serif 4 in tokens if a takedown ever arrives.
